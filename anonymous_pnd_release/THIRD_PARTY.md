# Scientific reference

The initialization of the diagonal temporal modes is related to the HiPPO
family of continuous-time memory constructions:

> A. Gu, T. Dao, S. Ermon, A. Rudra, and C. Ré, “HiPPO: Recurrent Memory with
> Optimal Polynomial Projections,” NeurIPS, 2020.

No dataset, pretrained weight, checkpoint, or third-party source tree is
distributed in this package. Dataset users must follow the licenses and terms
of the original dataset providers.
